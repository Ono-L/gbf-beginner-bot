# 主人公ジョブ（クラス）取得ロードマップと強化ガイド

## 主人公ジョブの体系（Class I〜IV・EX・EX II・Class V）

主人公のジョブは大きく「Class I〜IV」「EX／EX II」「Class V」の系統に分かれます。序盤はClass I→II→IIIと順番にレベル20まで上げて上位ジョブを解放し、Rank101以降で強力な「Class IV」および「EX II」へ進むのが基本ルートです。さらにClass IVジョブのマスターレベル（MLv）を30まで上げることで、最上位の「Class V」ジョブが解放されます。ジョブは取得してレベルを上げるだけで主人公全体に永続ステータスボーナス（コンプリートボーナス）が付与されるため、最終的に使わないジョブも半額期間やスライム周回でコツコツLv20にしておくと、編成全体の基礎火力が底上げされます。

## 序盤〜中盤で最優先に取るべきおすすめジョブ（Class IV・EX II）

Class IIIまでは攻防デバフとスロウが優秀な「ダークフェンサー」と、ドロップ率アップの「ホークアイ」が鉄板です。Class IV・EX IIに進んだら最優先で確保したいのが以下のジョブです。①「レリックバスター」：1ターン目から味方全員の奥義ゲージを100%にでき、短期周回・肉集め・日課の効率が劇的に上がります。②「剣豪（EX II）」：奥義ゲージ上限200%と圧倒的な奥義回転率を誇り、高難度からフルオートまで長く現役です。③「ランバージャック」：回復・弱体・バフを自動でこなすフルオート適正の塊で、初心者の難所突破に大活躍します。④「カオスルーダー」「ロビンフッド」：デバフ・ヒット数稼ぎに優秀です。

## Class V ジョブの解放条件と代表的な強み（パラディン・ヴァイキング・マナダイバー等）

Class Vジョブは、対応するClass IVジョブ2種類のマスターレベル（MLv）を30にし、専用フリークエストをクリアすると解放されます。どれも性能が非常に高く、中級〜上級で出番が激増します。代表的なおすすめは、①「パラディン」：全属性ダメカ・全体かばう・高耐久で高難度マルチの安定攻略に必須級。②「マナダイバー」：専用装備「ミニステル（マナベリ）」による自動追撃・アビダメで通常周回から高難度までトップクラスの火力。③「ヴァイキング」：高い通常攻撃火力と連撃性能で短期戦・古戦場周回に強い。④「ヤマト」：V2バトルの予兆解除に特化した高難度スペシャリスト。⑤「陰陽師」：高難度の弱体・ディスペル・耐久対応力が抜群です。

## 英雄武器（ジョブ専用武器）の作り方と優先作成候補（金重など）

「英雄武器（ジョブ専用武器）」は、EX IIジョブの解放条件や特定ジョブの性能を劇的に引き上げる専用メイン武器です。ショップの「特殊武器強化→英雄武器の作成」からレプリカ武器を強化して作成します。初心者が最初に迷ったら、最優先で作るべき1本は剣豪用の刀「**無銘金重（むめいかなしげ）**」に「魔獄」のエンブレムを付けたものです。奥義を撃つだけで味方全体の奥義ゲージが大幅に上昇し、毎ターン奥義を連発する「奥義ループ」が完成するため、水・土・光など複数属性で作成されるほどの超優秀武器です。その他、黒猫道士用の「ルナティックブルーム」や、陰陽師・ヤマト用の英雄武器も高難度で役立ちます。

## マスターレベル（MLv）と極致の証の仕組み・優先度

Class IV・EX IIジョブをLv20にしたあとに解放される追加育成が「マスターレベル（MLv、最大30）」です。MLvを上げるとジョブ固有の強力なサポートアビリティ強化や新アビリティが追加され、さらにClass V解放の前提条件にもなります。さらにMLv30到達後には「極致の証（最大Lv6）」が解放され、大量の素材とJPを投入することで既存Class IV・EX IIジョブに超強力な専用アビリティを追加できます。特に「ベルセルク」「レスラー」「カオスルーダー」「レリックバスター」「剣豪」「ライジングフォース」「ロビンフッド」「黒猫道士」などは極致の証の恩恵が非常に大きく、Class Vに匹敵する第一線級の性能へ化けます。

## 目的別おすすめジョブ早見ガイド（周回・フルオート・高難度）

どのジョブを使えばいいか迷ったときは、バトルの目的ごとに選ぶと失敗しません。①**短期周回・古戦場肉集め**：レリックバスター（奥義軸）、ヴァイキング・マナダイバー・ベルセルク（通常軸）、レスラー（ツープラトン）。②**フルオート（放置周回）**：ランバージャック（初心者向け安定）、マナダイバー（高火力）、パラディン・シールドスウォーン（高耐久）、剣豪（奥義フルオート）。③**V2高難度・レヴァンス・天元／ルシゼロ**：ヤマト（予兆解除）、パラディン（耐久・全体かばう）、剣豪（奥義軸）、陰陽師・マナダイバー（多機能支援・火力）。まずはレリックバスター・ランバージャック・剣豪・パラディンの4職を押さえると全コンテンツを広くカバーできます。
